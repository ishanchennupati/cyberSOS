# Current roadmap and scope

## Revised future Phase 4–12 contracts — 2026-10-02

The agreed requirements and supplied phase prompts are consolidated in
[the revised phase index and shared contract](phases/README.md). These documents
are execution prompts, not completed implementation or authorization to run every
phase. Start each major phase in a fresh conversation and execute one at a time.

| Phase | Scope |

**Required changes from supplied prompts:** Phase 4 must improve conversational
contracts, memory and curated retrieval alongside UI, rather than preserving all
Phase 3R wording restrictions. The first homepage CTA opens chat directly, with
one Send, no separate story form. UI and quality acceptance extend every phase.
Evidence, packets and secure return reuse the shared case/memory/projection paths.
Voice remains Phase 9; no fake microphone before support. Phases 11–12 retain
free-tier synthetic-only scope until separate real-data/spend/release authorization.

Core product invariants remain unchanged. No Phase 4–12 feature implementation
was performed as part of this roadmap update. Current runtime evidence remains
in [phase-status.md](phase-status.md) and the Phase 3R reports.
