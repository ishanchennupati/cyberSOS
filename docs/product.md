# Current product and limitations

README.md is the canonical capability summary. The current application uses
structured guided questions and limited category rules, not conversational intake
or comprehensive cybercrime playbooks. It prepares drafts, evidence metadata,
suspect/timeline records and local actions; the user reports independently.

The existing vault is a synthetic-data prototype. Private case capability authorization is implemented in Phase 1.
Retention and returning-user account recovery are not implemented. No government API integration,
submission confirmation, recovery prediction or live official progress tracking.
Optional providers are unverified and missing credentials must not prevent local
operation. Template summaries and manual evidence correction remain available.

AGENTS.md defines intended product invariants for future scoped work, not a claim
that the current interface implements them. Roadmap.md separates completed Phase
0/1 foundations from deferred conversation architecture. docs/legacy contains obsolete historical proposals.
