# Central official-source registry

The runtime authority is backend/app/domain/sources.py, not duplicated URL/rule
lists. Every active financial plan stores the exact source objects it used.
Actual Phase 1 review date: 2026-10-01. Sources support only the narrow reporting
claims below. CyberSOS is independent and predicts no recovery or official outcome.

No liability/refund/time rule adopted; not used for approved scam transfers |
| INDIA-EMERGENCY | [ERSS](https://112.gov.in) / [MHA ERSS description](https://www.mha.gov.in/en/commoncontent/emergency-response-support-system-erss) | Existing legacy 112 handoff; MHA indexed primary text reviewed; no response-time guarantee or new financial action |

Preservation, local follow-up, credential restrictions and urgency bands are
CyberSOS product policy, not purported official mandates. Sources do not promise
bank protection, police action, reversal or recovery. Future action claims must
review primary sources and record their actual review date. No review date is
fabricated for an unavailable source: fetch/index limits are recorded explicitly.
