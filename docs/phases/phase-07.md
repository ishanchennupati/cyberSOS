1. Expand the existing projection/view; no second case system. Relevant known facts,
   working understanding, actions/completions, evidence, identifiers, timeline,
   ReviewedCasePacket, notes and citizen-recorded external references.
2. Investigate session/identity and safe recovery options. UUID knowledge/bookmarks

   replay, theft and abuse. Minimize account friction without weakening ownership.
   If a consequential identity/recovery choice needs the user, present concrete

   Free-tier/synthetic constraints remain; do not provision paid identity services.
3. Restore canonical state and source-linked memory after return; do not rerun
   extraction/drafting on reads. New conversations use the same pipeline and revision
   checks. Clarify a distinct new incident before adding it to the existing case.
4. Support already-reported cases and natural updates. External bank/police/platform
   references are Recorded by you unless verified; no simulated investigation progress.
5. Citizen-owned notes, completion and evidence updates use existing authority and
   consistency. Do not imply external action completion merely from AI inference.
6. Specify implemented retention/deletion and secure return limitations. Clean case
   DB relationships, originals, derived memory, extraction, private indexes and
   caches; invalidate credentials. Document backup/log/provider limitations honestly.
